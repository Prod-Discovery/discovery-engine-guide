Why you need it

Less digging, more building the right thing

Discovery usually stalls in the gaps: reading feedback, waiting for workshops, writing specs, waiting for a prototype. The engine does the slow parts for you and leaves the decisions with you.

A validated, prioritised opportunity, with the evidence attached

Stop digging through spreadsheets, tickets and survey exports. The engine combines your customer data with competitor research and scores every opportunity on pain, market size, feasibility and strategic fit. You get a ranked list with the evidence and a confidence level for each one.

Weeks of idea-to-prototype, done in under a day

Research synthesis, prioritisation, requirements and a clickable prototype in one working session.

Validated end to end on a real Visma product

Run it end to end, or just the stage you need

Take the full journey, or jump straight in. Already have a PRD? Go to the prototype. Only need competitor research? Run that alone.

Prototype agentic products, not just screens

For AI and agent ideas, the engine designs the agent's behaviour first: what triggers it, what it decides, where it hands over to a person, and how it fails safely. An optional check applies Visma's guide for Great Agentic Experiences.

Prototypes that look like your product

It connects to your design system, Figma or component repo, or reads your screenshots. Users test something that feels real, so the feedback is real too.

Ready to test, not just to look at

Every prototype comes with an experiment plan: the riskiest assumptions, a hypothesis, success criteria and an interview script.

You stay in charge of every decision

The engine stops after each stage for your review. Every recommendation shows its reasoning, so you can defend it to your team.

Step 2 of 5

Install requirements

Check these two things before you install. It takes a minute and saves a confusing first run.

A paid Claude plan

Plugins need a paid plan: Pro, Max, Team or Enterprise. Free accounts don't have the plugin system. If you sign in to Claude with your Visma account, you already have this.

The Claude desktop app

The plugin runs in the Claude desktop app for macOS and Windows. It doesn't run in the browser version of Claude. On Pro and Max plans, Cowork may no longer have its own tab. That's fine, everything on this page still works. Download the desktop app if you don't have it yet.

Good to have for your first full run

Your product context Optional

A strategy doc or pitch deck, customer data exports (CSV) and the names of 2 to 4 competitors. You don't need them upfront. The engine asks for each one when it needs it.

Your design system or screenshots Optional

For a prototype that looks like your product: a connected Figma file, a component repo, or a few screenshots of your product. Without them you still get a working prototype in a neutral style.

Install from the plugin file

Your company's Claude workspace can't see Visma's plugin directory, so you install from a file. Want it set up for your whole team? Ask in #discovery-engine and we'll help.

  1. Download the plugin

    discovery-engine-plugin.zipAlways the latest version
    Download
    Save it somewhere easy to find, like your Desktop or Downloads folder.
    Check the file is genuine (optional)

    After downloading, run this in your terminal. The result should match the code below. If it doesn't, don't install it, and tell us in #discovery-engine.

    shasum -a 256 discovery-engine-plugin.zip

    Don't unzip it. Keep it as one file. If your Mac opened it into a folder, delete the folder and use the .zip file.

  2. Rename it to .plugin

    Right-click the file and choose Rename. Change only the ending, from .zip to .plugin, and leave the rest of the name as it is.

    discovery-engine-plugin.zip discovery-engine-plugin.plugin
    • If you're asked whether to change the extension, click Use .plugin.
    • If you don't see .zip at the end of the name, open File Explorer, go to View and turn on File name extensions. When Windows warns about changing the extension, click Yes.

  3. Upload the .plugin file

    Open the Claude desktop app, go to Customize, then Plugins, then Upload plugin. Select the .plugin file you just renamed.

  4. Confirm the install

    Confirm when Claude asks. The plugin then shows in Customize with its skills listed:

    Your version number and skill list will be newer than in this example.

  5. Start using it

    Click Try in Cowork on the plugin page. Installing doesn't open anything by itself, so this is the step most people miss. Or start a new task in Claude and type:

    You:/discovery-engine-start
    or just say
    You:Start the discovery engine

    See what happens next

Getting updates

File installs don't update by themselves. When a new version is out, /discovery-engine-start tells you. To update, remove the old plugin in Customize, then download the new file from this page, rename it to .plugin and upload it. Release notes go to #discovery-engine.

Use the Claude Code CLI? You can add the marketplace from your terminal instead: $ /plugin marketplace add Prod-Discovery/discovery-engine-plugin

Step 5 of 5

Help & feedback

Stuck, or want to go deeper? Start here.

I installed it, but nothing happened

That's expected. Installing doesn't open anything. Start a new task in Claude and type /discovery-engine-start, or say "Start the discovery engine".

I don't see a Cowork tab

On Pro and Max plans, Claude has started merging chat and Cowork into one view, so there may be no separate tab. You don't need it. Customize is still in the left sidebar, and the commands work in a new task.

Upload plugin won't accept the file

Check the file name ends in .plugin, not .zip or .plugin.zip. See step 2 of the file install.

Still stuck? Start a new task, drag the file into the message box and send "Please install this plugin". Claude installs it for you.

The plugin doesn't show up after I install it

Close and reopen the Claude desktop app. If it still isn't there, check that plugins are switched on in your Claude settings.

I can't find it under Your organization

Then your Claude account is probably in a different workspace from Product Discovery. Use the plugin file instead.

Which version do I have?

Open Customize and click into the plugin. The version is shown at the top. /discovery-engine-start also tells you if a newer one is out.

Something went wrong during a stage

The engine pauses at a checkpoint after every stage, so you can correct it, redo it, skip ahead or stop. Tell it what's wrong in plain words, the same way you'd brief a colleague.

I only want to run one stage

Every stage works on its own. See the list of stages and commands, or type /discovery in Claude.

Does the engine collect my data?

The plugin counts anonymous usage events, such as which stage was started or finished, so we can improve it. It doesn't collect names, emails, prompts or any of your content.
